feat(desk): name the file a phone adds to

A phone typed for a visit's unpaid part, at the check-out or in «تسجيل
دين», said nothing of whose file it would join (G13.12). Once the phone
is valid and typing pauses, the desk looks it up among the customers:
one found says «يُضاف إلى ملف {name}», none «زبون جديد بهذا الرقم», and
nothing is said while it is read. The server still decides at the
write; the line only says what it will find.

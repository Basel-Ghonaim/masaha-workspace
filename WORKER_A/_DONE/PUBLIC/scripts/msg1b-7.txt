fix(directory): say no count of zero

For an empty directory the count line («لا توجد مساحات في قطاع غزة بعد»)
sat right above the empty state («لا توجد مساحات في الدليل بعد»), and
for no match «لا توجد مساحات مطابقة» above «لا توجد مساحات تطابق ما
اخترت»: the same thing said twice. A count of none now draws no line;
each state says it once. The two zero lines leave the catalogue, the
zero form taking the counted one's words, as the type needs all six.

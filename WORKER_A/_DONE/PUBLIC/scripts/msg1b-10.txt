feat(directory): sort the spaces nearest first

U2's «الأقرب إليّ»: the device is asked for its location only when the
button is pressed; a position less precise than 2 km or outside the
Strip is not used, and of any other only the point rounded to three
decimals is kept, in memory only (S4), never in the address or the
browser's storage. While it sorts, the list is asked with sort=distance
and the point in the Masaha-Near header, never in the query a URL logs;
each card says how far it is (design issue 9).

Stopping keeps the point; «مسح موقعي» drops it and every answer ordered
by distance (design issue 6). The state line says each state, and the
privacy line (decision 8) shows only while a location is asked or sent
(design issue 5); a refused or imprecise one offers «اختر منطقتك»,
the place filter in the sidebar or the sheet (design issue 12).

## 7. Hazards learned this round

- A rebase can leave a conflict marker that no check catches (INDEX.md).
- `npm ci` in a folder open in VS Code can leave it half-installed (a locked native file).
- Copilot opened inside the repository runs the project's skills; open it outside.
- Free OpenCode models: per-model rate limits; long contexts break weaker ones; an agent with "no
  browser" writes an empty report — Chrome is at `C:\Program Files\Google\Chrome\Application\chrome.exe`.
- PowerShell 5.1 reads a UTF-8 script without BOM as ANSI: an em dash in a string breaks parsing.
- Restore a test's break from a backup copy, never `git checkout` (it wiped a worker's code once).

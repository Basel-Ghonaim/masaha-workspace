## 4. Architecture decisions to hold (all in the docs unless noted)

- **Frontend zones:** `app → pages → features → shared`. Page groups `site` and `dashboard`, with the layout tree in architecture.md §2.
- **Feature shape (H1–H8, §3):**
  - `repository/` (parameterless `createXRepository()` at module level), `hooks/` (`useXQuery` / `useX` / `useXForm`, `queryKeys.ts`), `components/` (render only), `services/` (pure), `types/`;
  - **features export UI first,** and hooks only when a higher layer composes them;
  - **features know no routes;**
  - **Context inside a feature is EXPERIMENTAL** (H8).
- **Testing:** testing.md, *A feature, layer by layer*.
- **The session:** `shared/session` (Zustand) with `repository/`, `services/`, `hooks/`.
  - **Statuses:** `restoring` / `authenticated` / `anonymous` / `unreachable` (with its reason). Only 401, or 403 `ACCOUNT_SUSPENDED`, ends a session.
  - **`passwordChanged`** checks that the same user is signed in.
- **Transport:** one Axios client. Retries only in the transport (GET or an `Idempotency-Key`); TanStack Query has `retry: false`, a 30 s `staleTime` and `networkMode: 'always'`.
- **Contract:** `packages/shared` is split by capability (`core`, `users`, `auth`, `space-links`, `lookups`), with subpath imports and levels enforced by lint (`docs/architecture/shared-package.md`).
- **Recovery:** a server-held recovery session (ADR 0017): an `HttpOnly` `masaha_reset` cookie, `GET /auth/password/recovery`, the token bound at the check, the reset reading it from the session.
  - A reset ends only the recoveries bound to a link (no existence oracle).
  - The email is sent before the answer (ADR 0014; finding 16 open).

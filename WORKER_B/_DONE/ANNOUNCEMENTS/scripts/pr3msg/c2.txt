feat(directory): answer a user's favourites

GET /me/favorites answers every favourite, whole (at most 200), as the
directory's cards: the public listing lists those still listed, with
their live statuses; the rest left the directory and are answered by
name, listed false, so the user can still remove them (C7).

Newest saved first; with sort=distance and the Masaha-Near header
(AC-014, Q9), the listed ones nearest first, those that left last. The
header's rule is the list's: its parsing is one function both routes
call, and an answer to a request carrying it is no-store, set before
the sign-in guard so its refusal is never kept either.

The directory gains a me router and favorites and spaces as deps; the
contract's §4 exceptions gain the list.
